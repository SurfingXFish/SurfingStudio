# 技巧：持续音（Pedal Point）

## 特点

一个音（通常是低音或高音）长时间保持，上方和弦/旋律变化。它制造“悬空”与张力，直到持续音移动或解决。

## 适用情况

- 桥段、前奏、尾奏、影视/氛围段落。
- 需要让和声变化听起来更“连贯”。
- 低音保持主音/属音，上方做和声色彩。

## 效果

- 稳定感与紧张感同时存在。
- 让上方变化更明显（不动的参照物）。
- 适合渐强、build、转调前的铺垫。

## 写法

1. 选一个持续音：主音（稳定）、属音（张力）、或五度（开放）。
2. 低音长音保持 2~8 小节；上方和弦每 1~2 小节变化。
3. 持续音可以在最后 1~2 拍移动半音/级进，形成解决。
4. 持续音不要与上方和弦的低音冲突；必要时省略上方和弦的根音。
5. 音色：大提琴、倍大提琴、合成器 Drone、管风琴。

## 示例

C 大调：低音 C 保持 4 小节，上方 `Fmaj7 – G7 – Am7 – G7`；第 5 小节低音下行到 B，进入 `Em7`。

## 禁忌

- 持续音与上方和弦的半音冲突没有解决。
- 持续音过长（超过 8 小节）且没有任何变化。
- 低音区同时有多个持续音，造成浑浊。
