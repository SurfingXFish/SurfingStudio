# 技巧：转调（Modulation）

## 特点

把调性整体移到另一个调，改变音高中心与和声色彩；可以突然（直接转调）或平滑（共同和弦/副属/半音过渡）。J-Pop 与影视配乐尤其常用。

## 适用情况

- 最后一次副歌需要升调。
- 桥段需要“换一个世界”。
- 长曲需要新鲜感。

## 效果

- 直接升调：能量瞬间提升（常升全音/小二度）。
- 关系调/中音转调：色彩变化，情绪更深。
- 半音中音：电影感、意外感。

## 写法

1. 升调：新调比原调高 1~2 个半音；桥段最后 1~2 小节用新调 V7 或 `♭VI–♭VII` 铺路。
2. 关系调：C 大调 → Am；用共同和弦 pivot。
3. 中音转调：C → Ab/E；用半音中音直接切入。
4. 共同和弦转调：两调共享的和弦作为桥梁。
5. 转调后旋律音区可升高，但不要超过乐器舒适区。

## 示例

C 大调副歌结束在 C；桥段最后 2 小节 `Ab – Bb`，最后副歌转到 Eb 大调（升小三度），旋律升到 Eb5。

## 禁忌

- 转调没有过渡，听众感觉“跑调”。
- 每次副歌都升调，变得廉价。
- 转调后乐器超出音域。
- 新调与旧调没有共同音/共同和弦，连接生硬。
