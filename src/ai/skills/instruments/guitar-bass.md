# 配器技能：吉他、贝斯与拨弦

## 1. 乐器与音域

| 乐器 | 记谱音域 | 实际/建议 | 备注 |
| --- | --- | --- | --- |
| AcousticGuitar（原声吉他） | E2~E6 | 实际低八度记谱；轻音乐多用 2~5 弦 | 分解和弦、扫弦 |
| ElectricGuitar1~4（电吉他） | E2~E6 | 清音/轻过载 | 色彩、副旋律、节奏 |
| AcousticBass（原声贝斯） | E1~G4 | 低音区 40~67 最常用 | 爵士/轻音乐低音 |
| ElectricBass1/2（电贝斯） | E1~G4 | 40~67 | 流行/轻爵士 |
| SynthBass（合成贝斯） | 28~67 | 40~60 | 电子/氛围 |
| Harp（竖琴） | C1~G7 | 琶音、滑奏 | 色彩层 |
| Banjo / Mandolin / Ukulele | 各自高音区 | 色彩点缀 | 民谣/世界风格 |

## 2. 原声吉他

### 2.1 标准调弦与常用把位

- 标准调弦：E2 A2 D3 G3 B3 E4（6→1 弦）。
- 开放和弦：C、G、D、A、E、Am、Em、Dm、F（大横按慎用采样）。
- 高把位（5~9 品）音色更柔和，适合轻音乐。

### 2.2 伴奏型

- 分解：`低音–3弦–2弦–1弦` 循环（指弹）；每拍 2 或 4 个音。
- 扫弦：4/4 下 `下 下上 上下上`；轻音乐用轻扫、靠近琴颈，避免金属感。
- 切分：Bossa 常用 `根音 + 和弦切分`，重音在 1、2&、4。
- 闷音（Palm mute）：只用于节奏点缀，轻音乐少用。

### 2.3 角色

- 和声节奏层：与钢琴分工，避免同音区同时密集。
- 色彩：尼龙弦/原声吉他在中高频有独特木质质感，适合副歌前的过渡。
- 对位：指弹可同时承担低音与旋律；注意不要与钢琴抢同一频段。

## 3. 电吉他

- 清音（Clean）：轻音乐、Lounge、Bossa；加合唱/混响。
- 轻过载（Crunch）：影视/摇滚轻音乐段；少量使用。
- 失真（Distorted）：只用于情绪爆发，轻音乐通常不用。
- 常见写法：单音旋律 + 推弦/滑音；和弦用 3~4 音（避免 6 弦全扫）。
- 音区：中高音区（E3~E5）最清晰；低音区与贝斯冲突。

## 4. 贝斯

### 4.1 角色

- 连接底鼓与和声，负责根音与低频走向。
- 轻音乐中“少即是多”：每小节 1~4 个音。

### 4.2 常用型

- 长音：每小节根音（二分/全音符），适合慢板。
- 根五：`根音（1拍）→ 五音（3拍）`，适合 4/4。
- 行走贝斯（Walking）：四分音符级进，连接和弦根音；适合轻爵士。
- Bossa：`根音（1）→ 五音（3）`，或 `根音–五音–八度–五音`。
- 切分：`1、2&、4` 等；不要过多，避免与旋律抢重音。

### 4.3 音区

- 40~55（E2~G3）最厚实；55~67 更清晰但接近吉他/钢琴低音。
- 避免低于 E1（28）的持续音；采样可能无力。
- 与底鼓：底鼓在 50~80 Hz，贝斯基频 40~100 Hz；编曲上让两者节奏错开或统一。

## 5. 竖琴与拨弦色彩

- Harp：琶音跨 2~4 个八度，每拍 4~8 个音；滑奏用于段落转折。
- 音区：C3~C6 最通透；低音区只做根音。
- 与钢琴：竖琴琶音更轻盈，可作为钢琴琶音的替代或叠加，但不要同时弹同一音型。
- 其它拨弦（Mandolin、Ukulele、Banjo、Pipa、Guzheng）见民乐/世界技能。

## 6. 力度与人性化

- 原声吉他分解 50~75；扫弦 60~85；电吉他清音 55~80。
- 贝斯 65~90；行走贝斯 70~85。
- 竖琴 50~80；滑奏可由低到高渐强。
- 同一和弦的扫弦不要每个音都 100；高音弦略轻。

## 7. 轻音乐中的编配建议

- 钢琴 + 原声吉他：让吉他弹分解、高把位，钢琴弹低音+长音，避免同频。
- 吉他 + 弦乐：吉他做节奏层，弦乐做长音；吉他音量略低。
- 贝斯 + 大提琴：二者都占低中频，选择一个做根音，另一个做对位或长音。
- Bossa：尼龙弦吉他切分 + 电贝斯根五 + 轻刷鼓 + 长笛/萨克斯旋律。
- 中国风：琵琶/古筝做点状旋律，吉他/贝斯做现代和声底座。

## 8. 常见错误

- 吉他六弦全扫 + 钢琴柱式 + 弦乐长音同时在中低音区 → 浑浊。
- 贝斯跟着旋律走 → 失去低音支撑。
- 电吉他失真铺满全曲 → 破坏轻音乐质感。
- 竖琴琶音速度过快、跨度过大 → 像音效而非伴奏。
- 吉他/贝斯写超出采样音域 → 变调失真。
