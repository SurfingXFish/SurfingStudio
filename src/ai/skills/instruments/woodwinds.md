# 配器技能：木管组

## 1. 乐器、音域与音色

| 乐器 | 实际音域 | 移调 | 音色与角色 |
| --- | --- | --- | --- |
| Piccolo（短笛） | D5~C8 | 实际高八度 | 极高音色彩；少量 |
| Flute（长笛） | C4~D7 | — | 清澈、灵动；主旋律/装饰 |
| Oboe（双簧管） | B♭3~A6 | — | 鼻音、穿透；抒情旋律 |
| Clarinet（单簧管） | D3~B♭6 | B♭ 移调 | 温暖、灵活；中音区旋律 |
| Bassoon（大管） | B♭1~E♭5 | — | 低沉、木质感；低音木管 |
| SopranoSaxophone（高音萨克斯） | A♭3~E6 | B♭ 移调 | 明亮；轻爵士旋律 |
| TenorSaxophone（次中音萨克斯） | A♭2~E5 | B♭ 移调 | 温暖沙哑；Lounge 主奏 |
| WoodwindLeg（木管连奏） | 21~108 | 采样 | 木管合奏铺底 |
| WoodwindStacc（木管断奏） | 21~108 | 采样 | 轻快节奏点 |

> 采样音色按 concert pitch 存储，写 MIDI 时直接写实际音高，不要再做移调。

## 2. 音区与表现力

- 长笛：C4~C5 柔和；C5~C6 最明亮；C6 以上尖锐，少用长音。
- 双簧管：B♭3~G4 略粗糙；G4~D5 最抒情；高音区紧张。
- 单簧管：D3~F3 暗；G3~C5 最温暖；C5 以上明亮。
- 大管：B♭1~C2 极低（需要气息）；C2~C3 厚实；C3 以上更具歌唱性。
- 萨克斯：中低音区温暖，高音区紧张；轻音乐优先中音区。

## 3. 木管的分工

- 长笛：高音旋律、装饰音、快速音型、与弦乐齐奏。
- 双簧管：抒情主旋律；鼻音容易被听见，不要与旋律同音区叠加。
- 单簧管：中音区旋律/对位；圆润，适合与钢琴/弦乐融合。
- 大管：低音线或低音对位；与低音提琴/贝斯形成木质低音。
- 萨克斯：Lounge/轻爵士主奏；音量大，注意留空间。

## 4. 常见写法

- 旋律：8 小节乐句，级进为主；长笛可用快速经过句。
- 对位：与主旋律错开 1~2 拍，形成问答。
- 齐奏：两支木管同旋律（长笛+双簧管、单簧管+萨克斯）；注意音准与音量。
- 和声：木管三/四声部，间距不要过密；低音区交给大管/巴松。
- 装饰：颤音、回音、快速音阶；轻音乐中少量使用。
- 持续音：长笛/单簧管长音铺顶，增加空气感。

## 5. 呼吸与人性化

- 木管是管乐器，长音要留换气：每 2~4 小节留一个八分休止或缩短音符。
- 不要写超过 4~6 拍的连续长音（大管更短）。
- 力度：旋律 75~100；对位 60~85；装饰 55~75。
- 快速音型前给一个轻微重音，句尾收弱。
- 采样木管的起音比弦乐快，但仍要避免过于机械的等长音符。

## 6. 轻音乐中的用法

- 长笛主旋律 + 弦乐铺底：最经典的轻音乐音色。
- 双簧管/单簧管在 B 段接替主旋律，形成音色对比。
- 大管与低音提琴/贝斯写低音对位，增加木质厚度。
- 萨克斯在 Lounge/Bossa 中主奏，配合电钢琴与刷鼓。
- 木管断奏用于轻快段落（2/4、进行曲），每拍 1~2 个音。
- 中国风：曲笛/梆笛/箫替代长笛，注意五声音阶与滑音。

## 7. 常见错误

- 木管与弦乐、钢琴在同一音区写同一旋律 → 音色互相抵消。
- 长笛长时间停留在 C6 以上 → 尖锐刺耳。
- 双簧管写密集和声 → 鼻音叠加，浑浊。
- 大管写快速音型 → 采样含糊。
- 忘记换气 → 不真实。
- 萨克斯音量过大、盖过整个乐队 → 需要降低力度或音量。
