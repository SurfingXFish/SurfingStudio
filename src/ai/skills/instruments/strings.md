# 配器技能：弦乐组

## 1. 乐器、音域与音色

| 乐器 | 实际音域 | 记谱 | 音色与角色 |
| --- | --- | --- | --- |
| Violin（小提琴） | G3~E7（常用 G3~C6） | 高音谱表 | 明亮、穿透；主旋律/高音对位 |
| Viola（中提琴） | C3~E6（常用 C3~C5） | 中音谱表 | 温暖、略带鼻音；内声部/副旋律 |
| Cello（大提琴） | C2~A5（常用 C2~C4） | 低音/次中音谱表 | 厚实、深情；低音旋律/对位 |
| Contrabass（倍大提琴） | E1~G4（实际低八度） | 低音谱表 | 低音根音；与贝斯二选一 |
| StringLeg（弦乐连奏） | 21~108 | 采样铺底 | 长音和声层，轻音乐核心 |
| StringStacc（弦乐断奏） | 21~108 | 采样 | 节奏点、轻快段落 |
| StringPizz（弦乐拨弦） | 21~108 | 采样 | 拨奏色彩、圆舞曲伴奏 |

## 2. 弦乐组的分工

- 第一小提琴：主旋律或高音和声。
- 第二小提琴：与第一小提琴三/六度平行，或对位。
- 中提琴：内声部填充，连接高低音。
- 大提琴：低音线或中低音旋律。
- 倍大提琴：根音；与贝斯不要同时写同一音型。

四声部写作（从高到低）：Vln1–Vln2–Vla–Cello；倍大提琴加倍大提琴低八度（谨慎）。

## 3. 音区与表现力

- 小提琴 G3~D4：温暖但略暗；D4~A5：最富表现力；A5 以上：明亮紧张。
- 中提琴 C3~G4：最温暖；G4 以上逐渐紧张。
- 大提琴 C2~G3：低沉厚实；G3~C4：最富歌唱性；C4 以上：高音区，紧张。
- 倍大提琴 E1~G2：低频支撑；更高音区少用。
- 避免所有弦乐都挤在 C4 附近；会造成“糊成一团”。

## 4. 弓法与发音

- 连奏（Legato）：长音、旋律、和声铺底；注意换弓呼吸。
- 断奏（Staccato）：短促、节奏点；适合轻快段落。
- 拨奏（Pizzicato）：圆舞曲伴奏、轻快低音；不要连续快速拨奏。
- 震音（Tremolo）：紧张/梦幻色彩；轻音乐少量。
- 泛音（Harmonics）：高音晶莹；色彩点缀。
- 滑音（Glissando）：段落过渡；谨慎使用。

## 5. 和声写作

- 弦乐长音是最安全的和声层：每轨一个音，形成 3~4 声部。
- 声部间距：低音区可宽（五度以上），高音区可密（三度）。
- 避免平行五/八度；内声部尽量级进。
- 和弦变化时，尽量保留共同音，让其余声部级进。
- 大提琴不要长期在高音区；中提琴不要长期低于 C3。

## 6. 织体

1. 持续音（Pedal）：低音长音 + 上方和声变化。
2. 弦乐铺底：4 个声部长音，每 2~4 小节换和弦。
3. 弦乐节奏型：八分/十六分重复音型，适合轻快段落。
4. 弦乐对位：与主旋律形成问答；不要与旋律同节奏。
5. 弦乐齐奏：所有弦乐同旋律，厚实但容易压过其它声部；高潮使用。

## 7. 轻音乐中的用法

- 标准配置：StringLeg 铺底 + 小提琴/大提琴独奏旋律。
- 小编制：Cello 低音 + Violin 旋律 + Viola 内声部。
- 圆舞曲：StringPizz 或弦乐断奏在 2、3 拍；大提琴/倍大提琴 1 拍根音。
- 抒情段：弦乐长音渐强，旋律交给长笛/双簧管/钢琴。
- 高潮：弦乐齐奏 + 铜管 + 定音鼓，但只持续 4~8 小节。
- 中国风：弦乐铺底给二胡/古筝/琵琶让出中高音区。

## 8. 力度与人性化

- 铺底 45~70；旋律 75~100；高潮 100~120。
- 长音做渐强/渐弱：可用多个音符分段，或整体力度曲线。
- 同一声部内不要所有音同一力度；句尾收弱。
- 弦乐起音有延迟，旋律音符可比网格略早 5~10 ms（采样起音更长时反而略晚）。

## 9. 常见错误

- 四个声部都在 C4 附近 → 中频拥挤。
- 倍大提琴与大提琴写同一音高 → 低频过厚。
- 弦乐全程长音、没有换弓与呼吸 → 呆板。
- 弦乐与钢琴/吉他写同一节奏型 → 相互遮盖。
- 弦乐铺底音量过大 → 压过旋律。
- 超出常用音区（小提琴低于 G3、大提琴高于 A5）→ 采样失真。
