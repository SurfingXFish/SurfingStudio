# 现代编曲与曲式技能

本技能补齐传统乐理之外的现代写作方法：段落功能、桥段、能量曲线、Hook、Groove 与现代和声。写作时先画“能量曲线”，再决定每一段用什么和声、织体与配器。

---

## 1. 现代曲式的段落功能

| 段落 | 功能 | 常见长度 | 能量 |
| --- | --- | --- | --- |
| Intro | 建立调性、速度、音色与氛围 | 2~8 小节 | 2~4 |
| Verse | 叙事、陈述主题、留空间 | 8~16 | 4~6 |
| Pre-Chorus | 蓄力、抬升张力、准备副歌 | 2~8 | 6~8 |
| Chorus | 核心 Hook、最高记忆点 | 8~16 | 8~10 |
| Post-Chorus | 副歌后的舞动/器乐 Hook | 4~8 | 7~9 |
| Bridge | 打破循环、提供对比、准备回归 | 4~16 | 4~7（先降后升） |
| Breakdown | 抽掉鼓/低频，制造悬空 | 2~8 | 2~4 |
| Build | 渐强、上升、滚奏、滤波打开 | 2~8 | 5~9 |
| Drop | 能量爆发、低频回归 | 8~16 | 9~10 |
| Solo / Instrumental | 器乐展示、变奏 | 8~16 | 7~9 |
| Outro | 收束、渐弱、终止 | 2~8 | 2~4 |

- 段落不是“越多越好”：32~64 小节内 4~6 个段落足够。
- 每段至少有一个“变化点”：和声、旋律、织体、音色、力度、节奏任一不同。
- 段落之间用 1~2 拍过渡（鼓过门、反向镲、空拍、贝斯滑音）。

## 2. 能量曲线

用 1~10 表示“听觉能量”，先写一行数字再写音符：

```text
Intro 3 → Verse 5 → Pre 7 → Chorus 9 → Verse 5 → Pre 7 → Chorus 9 → Bridge 5 → Build 8 → Chorus 10 → Outro 3
```

- 能量不只靠音量：层数、音区、节奏密度、和声张力、混响、低频都影响能量。
- 副歌比主歌高 2~3 级；桥段先降到 4~5，再在最后 2 小节抬到 7~8。
- 不要连续两个 9~10 的段落；中间要有 1 个 5~6 的呼吸。
- 结尾可以“反高潮”：最后一个副歌后突然只留钢琴/人声，再渐弱。

## 3. 桥段（Bridge / B Section）

桥段出现在第二次副歌之后，作用是“打破循环、提供新视角、让最后一次副歌更有价值”。

### 3.1 和声手法

- **关系小调/大调**：C 大调 → Am 小调；C 大调 → Eb 大调（关系大调）。
- **下属方向**：停在 IV 或 ii，制造“悬而未决”；如 C–F–Dm–G。
- **平行小调借用**：`♭VI`、`♭VII`、`iv`；如 C–Ab–Bb–G。
- **半音中音**：`♭III`、`♭VI`、`III`、`VI`；如 C–Eb–Ab–G。
- **副属链**：`V/vi → vi → V/ii → ii → V`，制造连续推进。
- **三全音替代**：用 `♭II7` 替代 `V7`，低音半音下行。
- **转调**：向上全音/小二度转调；桥段最后 2 小节用新调的 V7 锁住。
- **持续低音（Pedal）**：低音不变，上方和弦变化；适合氛围/影视。
- **线式低音（Line cliché）**：低音半音下行，如 C–Cmaj7/B–C/Bb–F/A。

### 3.2 旋律与织体

- 桥段旋律换一个动机，或把主歌动机倒影/拉长。
- 织体突然变薄（只留钢琴/弦乐/人声），再在最后 2 小节加鼓与贝斯。
- 节奏改半速（half-time）或改 3/4，制造“时间感变化”。
- 音色换新乐器（长笛、圆号、无词人声、合成器 Pad）。

### 3.3 回归

- 桥段最后 2~4 小节必须“铺路”：V7、鼓过门、上升音效、反向镲、空拍。
- 最后一次副歌可以升调、加高八度、加合唱/铜管，形成全曲最高点。
- 不要让桥段和副歌一样满；桥段的价值在于“对比”。

### 3.4 常见错误

- 桥段只是“另一个主歌”，没有新和声/新织体。
- 桥段太长（超过 16 小节）导致听众失去方向。
- 桥段结束后直接回副歌，没有过渡，显得突兀。
- 桥段和副歌同一音区、同一配器，能量没有落差。

## 4. 现代和声扩展

### 4.1 调式互换（Modal Interchange）

在同主音的大小调之间借用和弦：

- 大调借小调：`iv`、`♭VI`、`♭VII`、`♭III`、`v`。
- 小调借大调：`IV`、`V`、`♮6`、`♮7`。
- 例：C 大调中用 `Fm`（iv）、`Ab`（♭VI）、`Bb`（♭VII）；听感从明亮转向电影感/怀旧。

### 4.2 副属和弦

- `V/V`、`V/vi`、`V/ii`、`V/IV`；解决到目标和弦。
- 连续副属（`VI7 → II7 → V7 → I`）可以制造强烈的推进，但不要全曲使用。

### 4.3 三全音替代（Tritone Sub）

- 用根音相距三全音的属七替代原属七：`G7 → Db7`，二者共享 3、7 音（ enharmonic）。
- 低音形成半音下行（`Dm7 – Db7 – Cmaj7`），适合爵士/轻爵士/桥段。

### 4.4 半音中音（Chromatic Mediants）

- 根音相距大三度或小三度的和弦：`C → Ab`、`C → E`、`Am → F`。
- 共同音少，色彩突然；适合桥段、影视转折、副歌前的一击。

### 4.5 线式手法（Line Cliché）

- 低音或内声部半音移动，和弦性质随之改变：`C – Cmaj7 – C7 – F`。
- 小调版本：`Am – Am(maj7) – Am7 – Am6`。
- 适合前奏、桥段、尾奏；每条线只走 3~5 个音。

### 4.6 负和声（Negative Harmony）

- 以调式轴（C 大调常用 C–G 轴）镜像音高：C↔G、D↔F、E↔Eb、A↔Bb。
- 结果常把大调进行变成“同主音小调/弗里吉亚”色彩；适合桥段与重配和声。
- 不要全曲使用；把它当作“另一种配色”。

### 4.7 重配和声（Reharmonization）

- 保留旋律音，替换和弦：把旋律音当作新和弦的 3/7/9 音。
- 常用：`ii–V–I` 替代 `IV–V–I`；`♭II7` 替代 `V7`；连续下行五度。
- 每次只改 1~2 个和弦，保留原曲的可辨识度。

### 4.8 其它色彩

- `sus2/sus4`、`add9`、`6/9`、`m9`、`maj9`、`13`。
- 四度叠置（Quartal）：`1–4–7–3`，适合现代爵士/氛围。
- 上层三和弦（Upper Structure）：在属七上叠 `II` 或 `♭VI` 三和弦。
- 斜线和弦：`C/E`、`Am7/G`、`Fmaj7/A`，让低音级进。
- 持续低音 + 上方移动和弦：`C`  pedal 上的 `Fmaj7 – G7 – Am7`。

## 5. Groove 与节奏

- **Pocket**：音符相对网格的固定偏移；爵士略靠后，Funk 略靠前，轻音乐基本在网格上。
- **Backbeat**：2、4 拍军鼓/拍手；流行/摇滚的核心。
- **Half-time**：把军鼓从 2、4 改为 3（4/4 下），听感变慢、变重。
- **Four-on-the-floor**：每拍底鼓；House/Disco/轻电子。
- **Trap hats**：16 分三连音/滚奏；轻音乐中只做少量装饰。
- **Swing**：成对八分音符奏成 2:1；轻爵士/Blues。
- **Syncopation**：重音落在弱拍/弱位；用延音线跨小节。
- **Polyrhythm**：3:2、4:3；轻音乐中只用 1~2 小节，不要持续。
- **Note placement**：底鼓与贝斯同步；军鼓略后；踩镲略前；Pad 在网格上。

## 6. Hook 与 Topline

- Hook 类型：旋律 Hook、节奏 Hook、歌词 Hook、音色/制作 Hook。
- 副歌 Hook 通常 2~4 小节，音域窄（5~7 度），重复 2~4 次。
- 主歌音域低、节奏密；副歌音域高、节奏宽。
- 预副歌把旋律推到最高音前，副歌第一句落在高音或长音。
- 句法：问句（上行、停在 V）→ 答句（下行、停在 I）。
- 歌词与旋律重音对齐：重要词落在强拍/长音。
- 不要在副歌写太多词；留长音给听众记忆。

## 7. 编曲层次与频率

| 频段 | 内容 | 建议 |
| --- | --- | --- |
| 20~60 Hz | Sub / 底鼓基频 | 只留一个来源 |
| 60~250 Hz | 贝斯、底鼓、低音弦乐 | 控制密度，避免浑浊 |
| 250~800 Hz | 吉他/钢琴中低、人声厚度 | 容易堆积，适当减 |
| 800~2.5 kHz | 旋律、人声清晰度 | 主旋律核心区 |
| 2.5~6 kHz | 齿音、拨弦、铜管亮度 | 少量提升 |
| 6~12 kHz | 空气感、镲片 | 轻音乐可多一点 |
| 12 kHz+ | 极高频 | 少量 |

- 同一频段同一时刻只放一个“主角”。
- 低音与底鼓二选一做最低频；另一个让出。
- 旋律与主奏音色不要在同一音区完全重叠；用八度/音色区分。

## 8. 过渡与“电影感”

- **Riser**：白噪声/合成器上行 4~16 小节，在段落切换处释放。
- **Impact**：低频 boom + 镲片 + 噪声，落在 drop/副歌第一拍。
- **Reverse cymbal**：反向镲片，提前 1~2 拍。
- **Silence**：段落切换前 1 拍全体休止，制造“吸气”。
- **Filter sweep**：低通逐渐打开，制造“从水下到水面”。
- **Drum fill**：军鼓/通鼓 1~2 拍过门；每 8~16 小节一次。
- **Bass slide**：贝斯滑音进入新段落。
- **Vocal chop / 无词人声**：过渡色彩。

## 9. 常见现代风格配方

| 风格 | 速度 | 和声 | 节奏 | 配器 |
| --- | --- | --- | --- | --- |
| 现代流行 | 90~120 | `I–V–vi–IV`、`vi–IV–I–V` | 4/4 backbeat | 鼓+贝斯+钢琴/吉他+人声 |
| 电影/叙事 | 60~90 | 小调、半音中音、pedal | 自由/渐强 | 弦乐+圆号+钢琴+定音鼓 |
| Lo-fi | 70~90 | `maj7/m9`、`ii–V–I` | 松弛、略后拍 | 电钢+刷鼓+贝斯+黑胶噪声 |
| Ambient | 50~70 | 持续和弦、sus/add | 无鼓/稀疏 | Pad+钢琴+竖琴+钟琴 |
| City Pop | 95~115 | `maj7/9`、副属、转位 | 轻快 16 分 | 电钢+贝斯+吉他+鼓+弦乐 |
| Neo-classical | 60~80 | 自然音阶+借用 | 自由 | 钢琴+弦乐+大提琴 |
| Bossa Nova | 90~110 | `Imaj7–VI7–ii7–V7` | 切分 | 尼龙吉他+贝斯+刷鼓+长笛 |

## 10. 写作顺序（现代编曲）

1. 定能量曲线与段落表（每段 4/8/16 小节）。
2. 写副歌 Hook（先节奏后音高），确保 2~4 小节可记。
3. 写主歌与预副歌，让它们把 Hook 推出来。
4. 写桥段：换和声、换织体、换音色，最后 2 小节铺路。
5. 定低音与鼓的 Groove（底鼓、军鼓、踩镲三层）。
6. 加和声层（钢琴/吉他/弦乐/Pad）。
7. 加色彩与过渡（竖琴、钟琴、riser、impact）。
8. 删减：每段至少删一个声部，留呼吸。

## 11. 检查清单

- [ ] 段落表与能量曲线明确，副歌是全曲最高点。
- [ ] 桥段与主歌/副歌在和声、织体或音色上至少有两项不同。
- [ ] 桥段最后 2~4 小节有回到副歌的过渡。
- [ ] Hook 2~4 小节、音域 5~7 度、可重复。
- [ ] 低音与底鼓没有抢同一频段。
- [ ] 同一频段同一时刻只有一个主角。
- [ ] 每 8~16 小节有一次配器/织体变化。
- [ ] 过渡音效不盖过旋律；Drop/副歌第一拍有落点。
- [ ] 结尾有明确终止或反高潮设计。
