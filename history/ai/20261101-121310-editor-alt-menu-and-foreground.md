## 2. 任务目标

- 消除“按住 Alt/Ctrl+Alt → 弹窗短暂出现 → 应用假死”的现象。
- 避免宿主在插件弹出菜单打开期间强制重绘，把菜单刷掉。

## 3. 实际改动

| 文件 | 类型 | 改动说明 |
| --- | --- | --- |
| `vendor/vst3-host/src/window.rs` | 修改 | `plugin_window_proc` 对 `WM_SYSCOMMAND` + `SC_KEYMENU`、`WM_SYSKEYDOWN` + `VK_MENU` 直接返回 0；`is_foreground` 在前台窗口与编辑器属于同一 UI 线程时也返回 `true` |
| `src/plugin/editor.rs` | 修改 | VST2 编辑器窗口过程做同样的 Alt 系统菜单拦截 |
| `doc/技术文档.md` | 修改 | 6.7 本地 patch 说明 |
| `doc/项目简介.md` | 修改 | 2.4 补充 Alt 不再导致假死 |

## 4. 工作流变化

| 项目 | 变化前 | 变化后 | 影响 |
| --- | --- | --- | --- |
| 按 Alt / Ctrl+Alt | `DefWindowProcW` 进入阻塞的系统菜单循环，整个应用假死 | 窗口过程直接忽略该请求 | 不再假死；插件弹窗不会因此短暂闪现 |
| 插件菜单打开时的重绘 | 前台是插件的弹出窗口 → 编辑器被判为后台 → 每 200 ms 强制重绘 | 同一 UI 线程的前台窗口也算前台 | 菜单打开期间不再被宿主重绘打断 |
