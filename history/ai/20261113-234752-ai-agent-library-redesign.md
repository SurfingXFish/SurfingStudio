## 4. 工作流变化

| 项目 | 变化前 | 变化后 | 影响 |
| --- | --- | --- | --- |
| Agent 列表 | 每帧创建全部行与文字 | `show_rows` 只创建可见行 | 130 条乐器时布局成本与可见行数成正比 |
| 智能体默认乐器 | 每帧渲染 130 个复选框 | 默认只显示已选标签，弹出层内用虚拟化开关列表 | 编辑器每帧控件数从 130+ 降到个位数 |
| 乐器选择器 | 每帧克隆 130 条资料并构建 VST 选项 | 仅在弹出层打开时构建，列表虚拟化 | 避免每帧大对象克隆 |
| 页面视觉 | 平铺标题 + 单列表单 | 眉题/大标题/统计徽章 + 深底索引 + WORKBENCH 编辑器 + 分类胶囊 | 层次更清晰，更符合资料库工作台 |
| 输入区菜单 | 纯列表 | 标题/说明 + 全选 + 开关 + 页脚计数 | 选择状态更直观 |

## 8. 风险与后续

- 风险：`ScrollArea::show_rows` 依赖固定 56 点行高；后续若行内增加第二行说明或换行，需要同步调整 `AGENT_ROW_H`。
- 风险：页面仍每帧克隆一次 `AiLibrary` 快照（约 130 条乐器资料）；目前可正常交互，若资料量继续增大可改为借用或按 generation 缓存。
- 后续：如需更细的视觉主题，可为 Agent 页增加独立的强调色变量与卡片纹理，而不改动全局 IDEA 配色。
