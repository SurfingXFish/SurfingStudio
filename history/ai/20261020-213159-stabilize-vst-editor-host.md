## 2. 任务目标

- 撤销会干扰主窗口消息链的窗口过程钩子，消除输入/重绘/关闭被宿主影响的风险。
- 停止插件加载阶段的跨线程 `createView` 探测，GUI 只在 UI 线程创建并附加一次。
- 限制编辑器失败重试与尺寸查询频率，避免每帧创建/销毁原生窗口与临时视图。
- 保证删除/切换/退出时插件 detach 不会无限等待。
- 保留上一轮已完成的“实时”文案清理与卡片外侧宽度手柄。

## 4. 工作流变化

| 项目 | 变化前 | 变化后 | 影响 |
| --- | --- | --- | --- |
| 宿主窗口跟随 | 替换主窗口 `WNDPROC`，移动/缩放/显示时重定位 | 仅每帧同步卡片几何，矩形未变化不调用 `SetWindowPos` | 主窗口消息链不被宿主接管，降低卡死/输入异常风险 |
| 插件 GUI 创建线程 | 加载时在后台同步线程 `createView` 探测一次，UI 线程再创建真实视图 | 加载阶段不创建视图，只在 UI 线程创建一次 | 避免 VSTGUI 定时器/窗口绑定到错误线程导致的闪烁、挂起、崩溃 |
| 编辑器打开失败 | 每帧重试创建窗口 | `Failed` 记为失败并回退参数面板；`Busy` 才在下一帧重试 | 消除反复建窗造成的闪烁与卡顿 |
| 编辑器尺寸查询 | 缓存缺失时每帧查询（可能每帧创建临时视图） | 失败时最多每秒查询一次 | 降低 UI 线程与插件内部开销 |
| 编辑器 detach | `lock()` 无限等待 | 最多等待约 8 ms，超时隐藏窗口 | 删除/切换/退出时不再卡在插件锁上 |

## 8. 风险与后续

- 风险：独立宿主窗口是顶层窗口，主窗口拖动期间 GUI 只能在下一次 UI 帧跟上，可能出现短暂位移差；这是为换取消息链稳定而接受的折中。
- 风险：移除加载阶段 `createView` 探测后，少数“有 controller 但无视图”的插件会在首次打开时失败一次，随后回退参数面板。
- 后续：若残留进程仍无法结束，需要区分是插件在 `open_editor` 内挂起，还是终端权限（管理员/调试器）导致 `taskkill` 拒绝访问；建议用任务管理器以管理员身份结束并记录插件名称。
