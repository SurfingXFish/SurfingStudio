## 2. 任务目标

- 将工作区 Cargo 包从 edition 2021 升级到当前工具链支持的最新稳定版次 edition 2024。
- 按 edition 2024 的强制规则迁移 `unsafe` 代码与导出符号。

## 4. 工作流变化

| 项目 | 变化前 | 变化后 | 影响 |
| --- | --- | --- | --- |
| 内置延时/混响 DSP | 写指针与读取邻点使用 `% length` | 单步推进用 `if index == length { 0 }` 回绕 | 行为一致；省去每采样整数除法 |
| 压缩器增益 | 每采样 `log10` 求 dB，再 `10^(db/20)` 回算 | 每采样一次 `powf`：`(thr_lin / env)^(1 - 1/ratio)` | 阈值与比率语义不变；浮点末位略有差异 |
| 主总线 CPU 限幅 | 先乘主音量，再单独跑一遍 `soft_clip` | 同一趟完成 `soft_clip(sample * gain)` | 输出等价；少一次主总线全量读写 |
| 轨道声像 | 每块每轨 `cos`/`sin` | 等功率律闭式平方根 | 听感一致；去掉三角函数 |
| 乐器/效果器选择器 | 每帧深拷贝整份选项再排序 | 排序引用并缓存小写键 | UI 每帧分配显著减少 |
| `db_to_gain` | 压缩器内部辅助函数 | 已删除 | 函数表与文档同步 |

## 8. 风险与后续

- 风险：Rust 官方并不存在 “2026 edition”；本次按 2026 年工具链（rustc 1.99.1）支持的最新稳定版次 edition 2024 落地，未来发布新 edition 时仍需再次迁移。
- 风险：`vendor/vst3-host` 属于上游 vendored 代码，保持 edition 2021，未随主包升级。
- 风险：压缩器改为幅度域计算后，输出与旧实现存在浮点末位差异；阈值、比率与包络行为不变。
- 风险：Android 目标未在本次环境编译；合入前应在具备 NDK 的环境运行 `platforms/android/build.ps1` 验证 `#[unsafe(no_mangle)]` 导出与版本显示。
- 后续：版本号已按新周期递增到 `1.2.0a`，如需发布需走 `1.2.0a → 1.2.0t → 1.2.0` 流程并同步 `android:versionCode`。
