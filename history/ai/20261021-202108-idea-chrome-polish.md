## 2. 任务目标

- 修复应用栏左侧控件贴着顶部、与右侧窗口按钮不对称的问题。
- 打开“隐藏下拉栏”后只保留文件 / 编辑 / VST 插件 / 帮助，隐藏图标、下拉按钮与项目栏。
- 点击右上角或其他任意区域、按 Esc 时自动退出下拉栏状态。
- 按 IDEA New UI 重做应用栏与工具栏：中性灰配色、扁平按钮、圆角悬停、右对齐快捷键。

## 4. 工作流变化

| 项目 | 变化前 | 变化后 | 影响 |
| --- | --- | --- | --- |
| 应用栏布局 | `ui.horizontal` 行高按控件高度计算，左侧 24 点控件贴顶 | `ui.horizontal_centered` 固定 34 点高度并垂直居中 | 左侧与右侧窗口按钮上下对称 |
| 展开下拉栏 | 图标、下拉按钮、项目栏与四个菜单同时显示 | 左上角只保留文件 / 编辑 / VST 插件 / 帮助 | 与 IDEA 主菜单展开行为一致 |
| 退出下拉栏 | 需再次点击下拉按钮 | 点击菜单矩形以外任意位置或按 Esc 自动收起 | 切换更快；点击右侧按钮也会先收起菜单 |
| 项目栏 | 深色圆角块 + 青绿描边 | 扁平白字 + 下拉箭头，悬停显示灰色圆角 | 更接近 IDEA 的工程控件 |
| 设置入口 | 文本按钮“设置” | 自绘齿轮图标按钮 | 与应用栏图标语言统一 |
| 窗口按钮 | 46×36 满高，直角悬停 | 30×28 圆角悬停，关闭为 IDEA 红 | 更紧凑、留白更自然 |
| 工具栏控件 | 使用全局深蓝面板配色与默认按钮描边 | 局部改成透明底 + 圆角悬停，分隔线为细灰线 | 统一的扁平 IDE 风格 |
| 状态栏 | `BG_DEEP` 近黑底 | 与应用栏同色 + 顶部发丝线 | 上下 chrome 配色统一 |

## 8. 风险与后续

- 风险：菜单栏的“点击外部收起”依赖记录本帧菜单矩形；后续若在应用栏加入会弹出浮层的其他控件，需要一并纳入矩形判断或改用统一的菜单状态管理。
- 风险：工具栏在极窄窗口下仍会换行增高，属于预期行为；若需要固定高度需要额外的溢出菜单。
- 后续：如需进一步贴近 IDEA，可把工具栏文字按钮替换为图标按钮并补充图标组，以及为设置菜单增加可编辑的设置项。
