## 4. 工作流变化

| 项目 | 变化前 | 变化后 | 影响 |
| --- | --- | --- | --- |
| 新建工程 | `OpenProject { path: None }` 创建空白工程 | `NewProject { template: None / Some(id) }` | 支持空白工程、模板工程与范例工程 |
| 工程初始内容 | `reset_new_project` 只创建空白工程 | `reset_project_from_template` → `Project::from_template` → 模板展开 | 新窗口可直接得到多轨道编曲 |
| 主页导航 | 项目 / 插件 / 提示 | 项目 / 模板 / 插件 / 提示 | 模板页可搜索、筛选与一键创建 |
| 拨弦衰减 | 环路衰减按采样率换算并每采样应用 | 按基频换算为每周衰减，并补偿环路低通相位延迟 | 拨弦余音与音准更接近真实弦乐器 |
| 鼓件扫频 | 用 `t × f` 直接求正弦 | 相位累加 + 折回，金属噪声用固定非整数比 | 扫频无相位跳变，镲片更有金属感 |

## 8. 风险与后续

- 风险：原生乐器仍为实时 DSP，无法达到采样库的绝对真实度；网络资料主要提供参数范围，具体音色仍经过听感调参。模板与范例全部使用内置乐器，若后续调音色参数，已有 `.sfsd` 的声音会随之变化。
- 后续：如需采样级音色，可评估引入可再分发的轻量 SoundFont/采样后端；可继续为模板补充 3/4 拍、更多拉丁/非洲节奏与鼓组变体。
