## 1. 端到端工作流

### 1.1 启动与首帧

```text
main()
  ├─ decode_log_command（`--decode-log <文件>`：解码为 .txt 后退出，不创建窗口）
  ├─ diag::init（.sflog 二进制文件 + panic 钩子 + 诊断看门狗 + 资源采样）
  ├─ SetUnhandledExceptionFilter（异常时记 FATAL 并终止进程）
  ├─ gpu_render_startup（读取 GPU 界面渲染偏好）
  ├─ native_options（DX12 / Vulkan 且有可用 GPU → wgpu，否则 glow）
  └─ eframe::run_native
       └─ WindowHost::new
            ├─ theme::setup
            ├─ SharedServices::new
            │    ├─ AppSettings::load
            │    ├─ load_plugin_cache（插件记录与文件指纹）
            │    ├─ AudioRouter::new → start_output（全进程唯一输出）
            │    └─ MidiInputManager::new
            ├─ set_zoom_factor（用户界面缩放）
            └─ SurfingApp::new_home（根视口 = 主页窗口）
                 ├─ 读取设置/插件缓存快照
                 ├─ Engine::new + 注册到 AudioRouter
                 ├─ start_startup_scan（后台增量扫描，复用缓存）
                 └─ view = Home
```

日志锚点：`app.boot/process.start` → `log.ready` → `app.shell/window.root.create` → `app.boot/settings.load`、`plugin_cache.load`、`audio.open`、`shared.init` → `app.window/window.create` → `app.plugin/plugin.scan`。

安卓启动（NativeActivity 不调用 `main`，入口在独立 crate）：

```text
android_main（platforms/android/src/lib.rs）
  ├─ platform::install_storage(internal_data_path, ../cache)
  ├─ platform::install_activity(vm_as_ptr, activity_as_ptr)（SAF 需要的 JavaVM 与 Activity）
  ├─ diag::init（日志落在 <应用数据>/logs）
  ├─ NativeOptions { android_app: Some(app), renderer: Glow, .. }
  └─ eframe::run_native → WindowHost::new（与桌面相同）
       └─ single_window = !PlatformCaps::ANDROID.multi_window = true
```

单窗口模式下的差异（均按能力位判断，不写系统分支）：

```text
WindowHost::show_home            → home_viewport = true（主页占用根窗口，工程继续播放）
WindowHost::spawn_project        → 已有工程时拒绝并提示“当前系统只支持一个工程窗口”
WindowHost::draw_home_viewport   → 直接返回（不创建第二个 OS 窗口）
SurfingApp::open_roll_window     → 卷帘落在底部编辑区
SurfingApp::ui_settings_window   → 改为根窗口内的 egui::Modal
SurfingApp::begin_window_drag    → 直接返回（窗口由系统全屏管理）
save_project / export_wav        → 无对话框时写入 <配置目录>/Projects
打开项目…                        → platform::import_file → SAF ACTION_OPEN_DOCUMENT → 复制到 <数据>/Imported
工程副本/WAV 导出到公共目录…     → platform::export_copy → SAF ACTION_CREATE_DOCUMENT → detachFd 写入
VST 插件菜单 / 插件设置页        → plugin_hosting = false 时整体隐藏
```

SAF 导入的线程时序：

```text
工作线程（open_project_dialog / export_*_copy_to_public 内部线程）
  ├─ 组装 Intent → activity.startActivityForResult（JNI）
  ├─ RESULTS 队列上 wait_timeout（最长 600 s；UI 线程继续渲染）
  │     ↑ Android 主线程：MainActivity.onActivityResult → nativeOnActivityResult
  │                       → 读 uri/显示名 → 入队 + notify_all
  └─ 取消 → Ok(None)；成功 → detachFd 后 std::fs 复制 → 状态栏提示 → WindowAction::OpenProject
```

打开工程时的构造流程：

```text
WindowHost::open_project(path)
  └─ SurfingApp::new_project(ProjectStart::Open(path))
       ├─ 与其他窗口相同的公共初始化（共享快照 + 独立 Engine）
       └─ begin_load_project → 后台 ProjectRuntime::open_project
```

从模板/范例创建时的构造流程：

```text
WindowHost::open_new_project(template)
  └─ SurfingApp::new_project(ProjectStart::Template(id))
       ├─ 与其他窗口相同的公共初始化
       ├─ 标题使用 template::display_name(id)
       └─ reset_project_from_template → Project::from_template → build_project_with_bars
            ├─ 鼓组（16 分网格）
            ├─ 贝斯（和弦根音 + 节奏型）
            ├─ 和声（钢琴/吉他/弦乐/合成器）
            ├─ 主旋律（2 小节动机）
            └─ 铺底（可选合成器 pad）
```

首帧 `WindowHost::ui`：

```text
WindowHost::ui()
  ├─ diag::note_frame（UI 帧心跳）
  ├─ hotkeys::install（独立窗口空格钩子）
  ├─ 根窗口关闭请求（先记 window.close.request）：根是工程 → 加载/插件同步未完成时取消关闭并 request_close_when_ready；有未保存修改则保持窗口并弹出保存确认；否则关闭该工程并回到主页。根是主页且有工程 → 提升一个工程到根窗口；根是主页且无工程 → diag::request_exit("home_closed")（写尾帧 + TerminateProcess）
  ├─ update_window_titles（根工程与工程视口的唯一标题）
  ├─ draw_root（根窗口绘制 home 或 root 工程）
  ├─ 执行根窗口动作：ShowHome / OpenProject / NewProject / ResumeProject
  ├─ draw_home_viewport（根是工程且主页可见时绘制独立主页窗口）
  ├─ draw_projects（其余工程 show_viewport_immediate → SurfingApp::ui_frame）
  ├─ 执行工程视口动作、移除已关闭窗口、必要时轮询主页后台任务
  ├─ heartbeat::set_active + 请求下一次重绘（有工程时 16 ms）
  └─ diag::note_frame_duration（≥120 ms 记 ui.frame.slow）
```

`SurfingApp::ui_frame`：

```text
ui_frame()
  ├─ sync_shared_state（按 generation 拉取设置/插件缓存）+ resolve_native_window + 焦点归属
  ├─ theme::apply_style（首帧）
  ├─ hotkeys::register_window + heartbeat::install
  ├─ 指针按下 → begin_edit_gesture
  ├─ 关闭请求：can_close_now 为假 → CancelClose + request_close_when_ready（放弃未开始的加载，等后台同步结束）；否则有未保存修改 → CancelClose 并弹出关闭确认；否则销毁插件 GUI
  ├─ service_editors（编辑器窗口 + 处理器参数反馈）/ poll_scan / poll_plugin_probes / poll_midi / poll_load_project / poll_save_project / poll_autosave / poll_engine_sync
  ├─ close_after_ready 且 can_close_now → pending_close
  ├─ pending_close → ViewportCommand::Close（保存完成、用户放弃修改或后台加载结束）
  ├─ flush_pending_auditions（引擎锁被占用时暂存的试听事件按顺序补发）
  ├─ refresh_engine_snapshot（每帧一次 try_lock）
  ├─ handle_keyboard（本窗口空格 + 独立窗口空格钩子；浮动卷帘聚焦时钩子只消费不切换）→ validate_selection → update_roll_drag
  ├─ 插件参数变化处理（实时生效，无需重新渲染）
  ├─ sync_engine（播放中按关键常量节流）
  ├─ app_bar（含：点击图标请求显示主页；展开下拉栏后主页为第一项、设置为最后一项）
  ├─ status_bar（两种视图共用）
  ├─ WorkspaceView::Home → ui_home（侧栏 + 项目/模板/插件/提示页）
  ├─ WorkspaceView::Studio → main_toolbar / 底部卷帘 / inspector / arrangement
  ├─ window_resize_edges / update_roll_drag / ui_roll_windows / ui_lane_paste_prompt
  ├─ ui_browser / ui_instrument_picker / ui_help / ui_settings_window
  ├─ close_prompt → ui_close_prompt（保存并关闭 / 不保存 / 取消）
  └─ finish_inline_layout + commit_edit_gesture / end_edit_gesture + 请求下一次重绘
```

### 1.2 编辑工程

```text
UI 交互（ui/*）
  ├─ 直接修改 self.project 字段
  ├─ mark_dirty / bump_track_revision / bump_clip_revision
  └─ needs_sync = true
        └─ SurfingApp::ui → sync_engine
             └─ Engine::sync_project
                  ├─ 克隆 Project
                  ├─ 重建 TrackEngine / 插件实例
                  ├─ 缓存 any_solo / auto_stop_at / has_audio_clips
                  ├─ 按片段签名重建音符事件表（id/revision/start/length/notes.len）
                  └─ 保留音频源与源游标
```

### 1.3 播放与实时渲染

```text
toggle_play
  ├─ 引擎未播放 → Engine::play
  │    ├─ playing = true
  │    ├─ 清空音频源游标
  │    └─ reset_note_state（关闭全部音符并定位事件游标）
  └─ 引擎正在播放 → Engine::pause
       └─ reset_note_state

cpal 回调
  └─ Engine::process_output(&mut [Vec<f32>; channels])
       ├─ 未播放：试听中 → render_live；否则衰减电平
       ├─ 播放中：render_block → 循环/自动停止/块切分
       ├─ render_chunk：事件游标 → 乐器 → 音频片段 → 效果链 → 音量/声像 → 按 output_pair 混入主总线通道对
       ├─ 主效果器（前 L/R）→ 主音量（全声道）→ soft_clip / 实时 GPU 限幅
       └─ map_master_to_device（设备声道数）
```

### 1.4 实时渲染管线

```text
Engine::process_output
  ├─ 每轨从 event_cursor 取出本块 Note On / Off
  ├─ 合并试听事件并按力度自动化缩放
  ├─ 内置乐器 / VST 乐器渲染
  ├─ 音频片段按源偏移与弯音倍率流式混入
  ├─ 插入效果器链（wet 缓冲交换）
  ├─ 音量/声像 → 按 output_pair 累加到布局通道对
  ├─ 主效果器（仅前 L/R）→ 主音量（所有声道）
  ├─ 实时 GPU 开启：GpuRealtimeLimiter::process（最多 1 ms）→ 成功用 GPU 结果；失败/超时 CPU soft_clip
  └─ map_master_to_device → 设备输出

定位 / 播放 / 循环回绕
  └─ reset_note_state
       ├─ panic 乐器与效果器
       └─ seek_events（二分定位事件游标）

离线导出
  └─ Engine::render_offline_options(project, OfflineRenderOptions)
       ├─ 覆盖输出布局、关闭循环与自动停止
       ├─ 范围：整个工程（+ tail）或 loop_start..loop_end
       ├─ GPU 启用时 defer_master_clip = true（主总线只乘主音量）
       ├─ 逐块 Engine::process_output → 交错 2/6/8 声道
       ├─ GpuRuntime::apply_master_limiter（wgpu 计算着色器分块软限幅并回读）
       │    └─ 失败 → CPU soft_clip + 回退提示
       └─ OfflineRender { samples, channels, sample_rate, warning }
```

### 1.5 保存工程、自动保存与崩溃恢复

```text
save_project → save_project_as → save_project_in_background(force_dialog, autosave)
  ├─ 需要时弹出原生保存对话框（起始目录 = 设置中的默认存储地址）
  ├─ Engine::capture_plugin_states
  ├─ Project::clone（插件状态为 Arc<[u8]>，不复制大块）
  ├─ collect_peak_entries
  ├─ 后台线程：
  │    ├─ backup::create_backup（开启自动备份、且距上次版本 ≥ 300 秒）
  │    │    └─ 复制现有工程到 Backups/<工程名>-YYYYMMDD-HHmmss.sfsd，按保留数清理
  │    └─ ProjectRuntime::save_project
  │         └─ SfsdCodec::encode
  │              ├─ PLUG 原始状态块
  │              ├─ META zstd(MessagePack)
  │              ├─ PEAK zstd(MessagePack)
  │              └─ TOC + CRC
  └─ poll_save_project（校验 project_epoch / edit_seq）
       ├─ 成功且无新编辑 → dirty = false、删除崩溃恢复文件
       ├─ 关闭确认打开时 → pending_close → 下一帧 ViewportCommand::Close
       └─ 自动保存（autosave = true）→ 不写项目列表，状态栏显示“已自动保存”

poll_autosave（每帧）
  ├─ poll_recovery（恢复线程写盘结果 → 状态栏）
  ├─ push_recovery_snapshot（dirty 且 (project_epoch, edit_seq) 变化，最快每 5 秒）
  │    └─ RecoverySnapshot { project, peaks, target } → mpsc
  └─ tick_autosave（工程已有路径、dirty、无保存在进行、间隔 ≥ autosave_seconds；
     设置为 0 或低于 15 秒时跳过）
       └─ save_project_in_background(false, true)

崩溃恢复线程（每个工程窗口 1 个，独立于 UI 线程）
  ├─ 收到快照即缓存最后一份，按 20 秒间隔写盘（内容未变化时跳过）
  ├─ 目标路径：已保存工程 → 同目录 `<名称>.autosave.sfsd`
  │              从未保存 → `%TEMP%/SurfingStudio/<工程名>-<窗口编号>.sfsd`
  └─ 写盘使用 ProjectRuntime（原子替换），不接触 UI/引擎；窗口关闭时收到 Shutdown 退出

关闭窗口（X / 系统关闭）
  ├─ can_close_now 为假（加载解析 / 插件同步未结束）
  │    ├─ CancelClose → request_close_when_ready
  │    ├─ 丢弃 load_rx / loaded_project，清除 needs_sync / defer_sync
  │    └─ 后台同步仍在跑 → 显示“正在停止加载…”；同步结束后 pending_close → Close
  │         （超过 CLOSE_SYNC_TIMEOUT 5 秒 → abandon_engine + pending_close，强制关窗）
  ├─ dirty 或已显示确认 → CancelClose（根窗口由 WindowHost 判定）+ close_prompt
  ├─ 无未保存修改 → close_all_editors（VST3 先 `removed`/`setFrame(null)` 再 DestroyWindow；
  │    VST2 走 hide）→ 关闭视口；仅强制关闭/进程退出才用 destroy_for_exit 跳过插件清理
  ├─ “保存并关闭” → 保存成功后 pending_close → Close
  ├─ “不保存” → dirty = false、删除恢复文件 → Close
  └─ “取消” / 点击遮罩 / Esc → 继续编辑
```

### 1.6 加载工程

```text
open_project_dialog
  └─ 后台线程 platform::import_file（桌面：rfd 对话框；安卓：SAF 选择 + 复制到 <数据>/Imported）
       └─ begin_load_project
            └─ 后台线程 ProjectRuntime::open_project（工程运行时框架）
                 └─ ProjectRuntime::open
                      ├─ .sfsd → SfsdCodec::decode（core/project_runtime/sfsd/）
                      │    ├─ 校验 header / TOC / CRC / 版本
                      │    └─ 返回 ProjectSession（project + peaks）
                      ├─ .sndp → SoundBugCodec::decode（core/project_runtime/soundbug/）
                      │    ├─ 解析清单与媒体表
                      │    ├─ 解压并解析 comp.dat（EDIT 树）
                      │    └─ 返回 ProjectSession（project + warnings）
                      └─ 未知扩展名 → 按注册顺序探测全部可读后端
                           └─ poll_load_project
                                └─ apply_loaded_project（下一帧）
                                     ├─ 暂停音频、重置播放状态（begin_load_project 已先做一次）
                                     ├─ 关闭编辑器/浮动卷帘
                                     ├─ 旧工程异步析构
                                     ├─ 重置播放状态 / 清空撤销栈
                                     ├─ 恢复峰值波形（SoundBug 导入为空）
                                     ├─ ProjectSource::Imported：project_path = None、dirty = true
                                     ├─ defer_sync = true、sync_in_background = true
                                     └─ 下一帧 begin_async_sync
                                          └─ 常驻 STA 同步线程 Engine::sync_project_with(project, defer_plugin_instruments = true)
                                               ├─ 后台创建效果器实例；VST 乐器延后
                                               ├─ pump_plugin_messages 维持插件窗口/定时器
                                               └─ poll_engine_sync 应用结果与音频解码请求
                                                    ├─ mark_background_plugins（只记录效果器槽位）
                                                    └─ begin_instrument_load → 每帧 step_instrument_load
                                                         └─ Engine::sync_project_slice（时间片 ≤ 120 ms，至少一个插件）
                                                              └─ 全部就绪 → finish_instrument_load → finish_loading_state
```

### 1.7 插件扫描与加载

```text
启动（SurfingApp::new）
  └─ load_plugin_cache → start_startup_scan
       └─ start_scan_with(ScanMode::Incremental)
            └─ 后台线程 scan_incremental
                 ├─ PluginHost::list_plugin_files（标准目录 + 自定义 VST 路径，只枚举）
                 ├─ 指纹未变化 → 复用缓存记录
                 ├─ 新增/变化 VST3 → scan_vst3_paths（只读 moduleinfo）
                 └─ 新增/变化 VST2 → 只扫描所在目录
                      └─ poll_scan → 合并旧分类 + save_plugin_cache
                           └─ start_plugin_probes（仍未知的 VST3）

UI 打开浏览器
  └─ open_browser → start_scan（缓存为空时）
       └─ start_scan_with(ScanMode::All / Vst3 / Legacy)
            ├─ 后台线程 PluginHost::scan_plugin_format
            └─ poll_scan → plugin_cache + 指纹 + 缓存文件
                 └─ start_plugin_probes
                      ├─ 后台线程 PluginHost::probe_plugin_metadata(Vst3, path)
                      └─ poll_plugin_probes → 逐项替换缓存记录并写盘

选择插件
  └─ apply_plugin
       ├─ cancel_plugin_probes（停止后台识别，释放加载器锁）
       ├─ PluginRef::new / 写入轨道或主输出 / invalidate_plugin_params / bump_track_revision
       ├─ sync_engine（UI 线程）：TrackEngine::ensure_instrument / ensure_effects
       │    └─ PluginHost::load_plugin → PluginRuntime
       ├─ 若已有后台同步在跑 → pending_plugin_apply，等 poll_engine_sync 后收尾
       └─ finish_plugin_apply（读取名称/类型、写回实例状态与插件缓存）
```

内置插件资料库（`plugin/catalog.rs`）在扫描记录创建时补全缺失的厂商、分类与角色，不改变扫描流程。

打开工程（后台同步）
  └─ begin_async_sync → 常驻线程创建效果器实例 → poll_engine_sync
       ├─ mark_background_plugins（只记录效果器槽位）
       ├─ begin_instrument_load → 每帧 step_instrument_load（时间片补载 VST 乐器）
       ├─ finish_instrument_load → finish_loading_state
       └─ 首次打开效果器 GUI → ensure_ui_thread_instance
            ├─ capture_plugin_states（状态写回工程）
            ├─ invalidate_plugin_slot（只丢弃该槽位运行时）
            └─ sync_engine（UI 线程重建实例）→ open_editor / open_inline_editor

开始播放
  └─ toggle_play → prepare_playback_plugins
       ├─ capture_plugin_states
       ├─ 每个 background_synced 槽位标记 restore_state
       ├─ invalidate_plugin_slot（逐槽位）
       └─ sync_engine（UI 线程重建）→ 再启动传输

### 1.9 SoundBug 工程导入

```text
SoundBugCodec::decode
  └─ import_project
       ├─ parse_sndp
       │    ├─ 校验 SNDP 魔数 / 属性表
       │    └─ parse_media：名称、类型、相对路径、时长 → comp.dat 路径
       ├─ read_comp：zlib 解压 comp.dat（上限 MAX_COMP_BYTES）
       ├─ parse_edit：EDIT 树
       │    └─ Reader::read_node：属性数量 + 属性 + 子节点数量 + 子节点
       ├─ read_bpm / read_time_signature / read_master_volume
       ├─ import_track（TRACK / WAVETRACK）
       │    ├─ parse_plugin / instrument_for / plugin_ref
       │    ├─ import_midi_clip：NOTE.b / NOTE.l（beat）
       │    └─ import_audio_clip：start / length / offset（秒）→ AudioSource.offset_seconds
       └─ 组装 ProjectSession（source = Imported；app 层置空 project_path，只允许另存为 .sfsd）
```

### 1.10 关闭工程窗口（应用继续运行）

```text
WindowHost::ui（根窗口关闭请求，root=project）
  └─ close_root_project → root_project = None → SurfingApp::drop
       ├─ diag：window.drop phase=begin（记录插件乐器/效果器数量与线程 id）
       ├─ AudioRouter::unregister（从音频路由移除；音频回调下一块释放缓存的强引用）
       ├─ engine.try_lock().pause()，最多等 200 ms 让音频/后台线程释放引擎引用
       ├─ 断开常驻后台插件同步线程、停止崩溃恢复线程
       ├─ 销毁并 forget 插件编辑器窗口（跳过 removed()）
       ├─ forget 撤销/重做栈（大对象不在关闭路径析构）
       ├─ 若有进行中的保存，最多等 3 s
       └─ 工程含插件实例 → forget 一个引擎强引用（插件实例保留至进程结束，日志 phase=engine_retained）
          纯内置乐器 → 引擎字段在 drop 返回后正常析构（日志 phase=engine_drop_next）
  └─ 根窗口切回主页，进程继续运行
```

插件析构不可中断：VOCALOID VSTi / ACE Bridge 等插件会在析构中等待 UI 消息循环，在 UI 线程直接析构会永久卡死，换线程析构可能触发 `0xC0000005`，因此含插件的工程采用“保留引擎”策略。

### 1.11 导出音频（独立窗口）

```text
Ctrl+E / 文件 → 导出音频… → export_wav_dialog → open_export_window
  ├─ 首次打开：填入默认路径（工程目录 / 默认存储地址 / 平台工程目录）与默认参数
  └─ ExportState.open = true

ui_export_window（桌面视口 / 单窗口平台模态）
  ├─ 修改格式、位深、采样率、声道布局、范围、尾长、GPU、路径
  ├─ 切换格式 → ensure_extension 同步扩展名
  ├─ 「选择…」→ export_pick_path（后台 save_file）→ poll_export_dialog 回填路径
  └─ 「开始导出」→ start_export
       ├─ 暂停传输、抓取插件状态、克隆工程快照
       ├─ OfflineRenderOptions { sample_rate, layout, range, tail_beats, gpu }
       ├─ AudioEncodeOptions { sample_rate, channels, bit_depth }
       ├─ 后台线程 AudioRuntime::export_project_with_options
       │    ├─ Engine::render_offline_options → 交错多声道样本
       │    └─ AudioRuntime::export_with_options → WAV / AIFF
       └─ poll_export：更新窗口状态与状态栏
```

## 5. 关键调用链

### 5.1 编辑 → 实时生效

```text
ui_* 修改 Project
  → mark_dirty / bump_*_revision
  → SurfingApp::ui
  → sync_engine
  → Engine::sync_project
  → track.revision / clip.revision 变化
  → TrackEngine::refresh_events 重建并排序音符事件
  → 下一音频块从 event_cursor 读取新事件
```

### 5.2 播放与定位

```text
Engine::play
  → 清空音频源游标
  → reset_note_state（panic 乐器/效果器 + seek_events）
  → 实时回调立即渲染当前播放头

Engine::seek
  → 更新 position_beats
  → 清空音频源游标
  → reset_note_state（事件游标二分定位）

循环回绕
  → position_beats = loop_start
  → reset_note_state
```

### 5.3 插件 GUI 参数变化

```text
Plugin GUI 修改参数
  → Engine::poll_parameter_changes（按参数轮询间隔）
  → TrackEngine::poll_parameters
  → 返回变化的 TrackId
  → SurfingApp::ui 仅更新状态栏提示
  → 实时实例已经按新参数发声，无需重新渲染
```

独立编辑器打开时的分析器/电平反馈：

```text
SurfingApp::service_editors（每帧）
  → 窗口 service（VST2 idle / VST3 resize 服务）
  → Engine::service_editor_feedback(track_id, slot)
  → PluginRuntime::pump_editor_feedback
  → 处理器输出参数 → vst3-host 回写 IEditController::setParamNormalized
  → 插件 GUI 分析器持续刷新（与效果器卷帘是否可见无关）
```

### 5.4 文件加载/保存并发保护

```text
保存
  ├─ 克隆 Project 快照
  ├─ 记录 edit_seq / project_epoch
  └─ 后台写盘
       └─ poll_save_project
            ├─ epoch 不一致 → 丢弃结果
            ├─ edit_seq 一致 → dirty = false
            └─ 关闭确认打开且无新编辑 → pending_close

崩溃恢复
  ├─ UI 线程每 5 秒（内容变化时）投递快照到 mpsc
  ├─ 恢复线程缓存最后一份，独立按 20 秒间隔写 `<名称>.autosave.sfsd`
  ├─ 写盘使用 ProjectRuntime（`.tmp` + 原子替换），不与 UI 线程保存共用临时文件
  └─ 工程保存成功 / 用户放弃修改 → 删除恢复文件并重置推送标记

加载
  ├─ 后台读取/解析
  ├─ loaded_project 暂存
  └─ 下一帧 apply_loaded_project
       ├─ project_epoch + 1
       ├─ 清空历史 / 重置播放状态
       └─ defer_sync 一帧后同步
```

### 5.5 SoundBug 导入 → 同步

```text
begin_load_project(.sndp)
  → ProjectRuntime::open_project
       → ProjectRuntime::open → SoundBugCodec::decode
            → import_project
                 → parse_sndp / read_comp / parse_edit
                 → import_track / import_midi_clip / import_audio_clip
  → poll_load_project
  → apply_loaded_project（source = Imported）
       ├─ project_path = None
       ├─ dirty = true
       └─ defer_sync = true
  → Engine::sync_project
  → spawn_audio_loads（后台解码音频片段）
```

### 5.6 主页 → 打开工程窗口

```text
ui_home_projects（单击项目）/ “打开项目”对话框 / Ctrl+N
  → open_recent_project / request_new_project / poll_load_project
       ├─ 文件缺失：settings.remove_recent + commit_settings，停留主页
       └─ pending_window_actions += OpenProject { path }
            → WindowHost::take_actions → open_project
                 ├─ 同一路径已打开：只置前已有工程窗口 + 隐藏主页
                 └─ 新建 SurfingApp::new_project
                      ├─ ProjectStart::New → reset_new_project
                      └─ ProjectStart::Open(path) → begin_load_project
                           → ProjectRuntime::open_project
                           → poll_load_project → apply_loaded_project
                                ├─ 非 Backups 历史版本：settings.push_recent + commit_settings
                                └─ defer_sync 后进入插件同步
            → hide_home（主页窗口 Visible(false)，工程窗口保持打开）

ui_home_project_row（点击箭头）
  → home_project_expanded 切换
  → ui_home_project_details
       ├─ request_home_project_info（后台 ProjectRuntime::open_project → 摘要）
       ├─ backup::backup_versions（Backups/<工程名>-时间戳.sfsd）
       └─ “打开历史版本” → WindowAction::OpenProject（不写入项目列表）
```

## 6. 维护规则

1. 新增文件：更新第 2 节模块地图与第 3 节函数索引。
2. 新增/删除/重命名函数：更新对应文件表格中的函数行与功能描述。
3. 改变调用顺序或数据流：更新第 1 节端到端流程与第 5 节关键调用链。
4. 新增跨层依赖：先更新 [技术文档](./技术文档.md) 的架构章节，再更新本文档。
5. 新增/修改常量：同步更新 [关键常量](./关键常量.md)。
6. 本文档只记录“入口 + 职责 + 流程”，不复制实现细节；避免与源码重复维护。
